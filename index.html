02 — SEO

SEO at scale.

Technical, international and generative-search SEO for a portfolio of high-traffic consumer products in 30+ languages — the foundation the tools are built on.

84%of ~8M verified Googlebot hits went to API endpoints, not pages

Googlebot crawl waste, found in server logs

Problem
Nobody knew where Googlebot actually spent its crawl budget.
What I did
Analysed ~8M Googlebot requests from server logs, verified real bots by IP and grouped URLs by shape. Found that most of the crawl went to API endpoints and that ~30K hits came from fake Googlebots.
Result
An “always server-side render for Googlebot” fix, and a permanent crawl monitor (~1M verified fetches a day) inside SEO OS.
